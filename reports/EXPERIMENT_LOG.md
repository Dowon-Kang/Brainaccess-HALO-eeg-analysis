## V-01 — 저장된 결과의 일관성과 모델 선택 편향 진단

- **STEP 1 이전 결과:** methods.csv 19개 파이프라인, 기준선(ERP 4채널 + sLDA) 평균 33.8%, 최고 평균 39.6%(ERP O1·O2 + sLDA). subjects.csv: P002만 Bonferroni 후 유의.
- **STEP 2 문제:** 같은 CV로 19개를 비교해 최고값을 고르면 선택 편향이 생긴다. 차이가 잡음 수준인지, CSV가 서로 맞는지 확인이 필요하다.
- **STEP 3 가설:** H1a 저장된 CSV는 서로 산술적으로 일관된다. H1b 파이프라인 간 차이는 참가자별 순열 null 변동과 같은 크기다. 반증: 불일치 발견(H1a) / 최고-기준선 차이가 null SD의 수 배 이상이고 참가자 간 순위가 일관됨(H1b).
  독립변수: 파이프라인. 종속변수: 저장된 BA. 통제: 저장된 CV 그대로(재실행 불가).
- **STEP 4 설계:** 원본 없이 가능한 범위. 순열 null SD는 (null95 − null_mean)/1.645 정규근사. 참가자 1명씩 빼고 나머지 3명 평균으로 파이프라인을 고른 뒤 빠진 참가자의 점수를 읽는 교차-참가자 선택.
- **STEP 5 실행:** `python research/validation/v01_results_audit.py` · 0.8 s · 입력 CSV 5개(Shape methods 19×9, subjects 4×10, sessions 10×7, controls 6×5, generalization 16×4) · 출력 `reports/runs/V01/*.csv`, `reports/figures/V01_pipelines_vs_null.png`.
- **STEP 6 결과 (관찰된 사실):**
  - 일관성 검사 **28/28 PASS** (평균·Δ·시행 수 합·Bonferroni ×19·이항 임계값·표 간 교차값).
  - 순열 null SD(암시값): P002 2.55, P003 3.53, P08 5.23, P001 5.90 %p → iid 이항 SD의 **1.25, 1.17, 1.29, 1.14배**. 따라서 `controls.csv`의 이항 chance95는 실제 null보다 관대하다.
    *정정(V-03b 이후):* 처음에는 이 비율을 "시행이 독립이 아니라는 신호"로 해석했으나, 시행 잡음이 완전히 독립인 합성 데이터에서도 같은 비율(1.11–1.28배)이 나왔다. 이 초과 분산은 CV에서 fold마다 모델이 달라지는 데서 오며, 시행 간 의존의 증거가 아니다.
  - 최고-기준선 차이 3.4–10.9 %p. 독립 정규 19개의 기대 최댓값(1.84 SD)으로 환산한 null 최댓값 기준선: P002 37.6, P003 39.4, P08 42.2, P001 43.0% (상관된 파이프라인이므로 실제 기대 최댓값은 이보다 작음 → 상한 참고치).
  - 교차-참가자 선택: 4번 모두 **ERP O1·O2 + sLDA** 선택. 빠진 참가자 점수 44.7 / 39.4 / 36.0 / 38.2% (평균 39.6%). P002·P003만 그 참가자의 null95를 넘음.
  - 순위 일치도 Kendall's W = 0.409 (χ²(18) = 29.5, p = 0.043, 파이프라인 간 상관 때문에 근사), 참가자 쌍 Spearman ρ −0.07 ~ 0.52.
  - 파이프라인×참가자 76칸 중 18칸이 그 참가자 null95 초과 (null95는 O1·O2 파이프라인에서만 추정 → 참고치).
- **STEP 7 판정:** H1a **KEEP**(지지). H1b **INCONCLUSIVE** — 대부분의 파이프라인 차이는 null 변동 크기지만, "ERP O1·O2 + sLDA"가 교차-참가자 선택에서 일관되게 뽑혀 단순 잡음만은 아닐 수 있다. 단 이 점수 자체가 V-04의 평가 결함(쌍둥이 블록, 시행 단위 순열)에 노출되어 있어 판단을 보류한다.
- **해석 한계:** 모든 수치는 재생성할 수 없는 저장된 집계값에서 나왔다.

- **가설:** 설정된 RGB(157,0,0)/(0,89,0)/(0,0,255)와 회색 (76,76,76)은 이상적 sRGB 디스플레이에서 등휘도다. 반증: 상대 휘도 차이 > 5%.
- **실행:** `python research/validation/v02_stimulus_luminance.py` · 0.01 s · 입력 `rgb-eeg-lab/config/protocol.json` · 출력 `reports/runs/V02/stimulus_photometry.csv`.
- **결과 (관찰된 사실, 명목값):** Y_rel R 0.0717, G 0.0714, B 0.0722, 회색 0.0723 → 회색 대비 Michelson 대비 −0.39%, −0.58%, −0.07%. CIE xy: R (0.640, 0.330), G (0.300, 0.600), B (0.150, 0.060). 원뿔 대비(회색 기준, Hunt–Pointer–Estevez 근사): S-원뿔 R −0.92, G −0.85, **B +11.1**; L-원뿔 R +0.47, G −0.12, B −0.36.
- **판정:** 명목 등휘도 가설 **KEEP**(지지). 단 물리적 모니터 측정이 없어 실제 휘도 차이는 UNKNOWN(측광기 필요). 세 색은 원뿔 자극 양상이 크게 다르며(특히 B의 S-원뿔), 이는 교란이 아니라 색 자체의 차이다. 해석할 때 "색상"보다 "원뿔 경로별 반응"으로 기술하는 편이 정확하다.

## V-03 — 저장된 19개 파이프라인의 합성 null 보정·민감도 (누수 점검)

- **STEP 1 이전 결과:** 원 분석의 `synthetic_check.py`(실제 배경 EEG + 가짜 마커)는 결과가 저장되지 않았다.
- **STEP 2 문제:** 평가 코드가 색 정보 없는 데이터에서도 우연 수준 이상을 내는지(누수·편향) 확인해야 Baseline 비교가 의미를 갖는다.
- **STEP 3 가설:** H3 색 정보가 없으면 모든 파이프라인의 leave-one-block-out BA 기대값은 1/3이다. 반증: 어떤 파이프라인이든 20회 평균이 1/3 + 3 SE를 넘음. 보조: 1.5 µV 색 효과 주입 시 ERP 파이프라인 BA 상승.
  독립변수: 파이프라인(19), 조건(null / signal). 종속변수: BA. 통제: 같은 합성 데이터(반복마다 동일 데이터를 모든 파이프라인에 적용), 같은 CV(`rp.evaluate`, 블록 그룹), 세션별 다른 seed(쌍둥이 구조 없음).
- **STEP 4 설계:** 합성 피험자 = 3세션 × 180 obs 시행(P002 규모, n = 540, 15블록), 4채널 1/f 배경(SD ≈ 8 µV) + 후두 알파 + 색 무관 onset VEP. null 20회, signal 5회(F6 nested는 연산량 때문에 각 3회).
- **STEP 5 실행:** `python research/validation/v03_synthetic_leakage.py 20 5` · 717.8 s (4코어) · 입력 Shape X (540, 4, 840) / 반복 · 출력 scores (431 × 5), `reports/runs/V03/summary.csv`, `reports/figures/V03_null_calibration.png`. run.json의 file_sha256은 실행 후 계산(실행 중 스크립트 미변경).
- **STEP 6 결과 (관찰된 사실):**
  - null 평균 BA: 0.331 (F4b RBF-SVM) ~ 0.347 (F2a ERP O1·O2 + sLDA), 전체 평균 0.340. 어떤 파이프라인도 1/3 + 3 SE를 넘지 않음(최대 t = 2.63, F2a ERP 4채널 + sLDA; 18개 상관 검정 중).
  - 반복 간 SD 0.017–0.033 (n = 540의 iid 이항 SD 0.020). 같은 null에서도 단일 반복 점수는 24.6–39.8% 범위.
  - 1.5 µV 주입: ERP 기반 파이프라인 0.351–0.368 (null 대비 +1–2 %p), xDAWN·밴드파워·공분산 계열 0.340–0.343 (변화 거의 없음). 5회라 민감도 근거는 약함 → V-03b에서 보강.
- **STEP 7 판정:** H3 **KEEP** (라벨 누수 증거 없음). 일부 ERP 파이프라인의 null 평균이 1/3보다 1.2–1.4 %p 높게 나온 것이 우연인지 V-03b로 확인.
- **신호처리 관점:** 단일 실행 BA 36–39%는 n ≈ 500에서도 null 분포 안에 들어간다. 참가자 단위 순열검정이 필요한 이유를 수치로 보여 준다.

## V-03b — V-03 후속: 핵심 ERP 파이프라인 2개의 null 편향 정밀 추정과 민감도

- **문제:** V-03에서 F2a ERP(4ch)+sLDA와 F2a ERP(O1,O2)+sLDA의 null 평균이 1/3보다 1.2–1.4 %p 높았고(20회), 민감도 근거가 약했다.
- **가설:** H3b 두 파이프라인의 null 기대값은 1/3이다(반증: 200회 평균의 95% CI가 1/3을 벗어남). 색 효과 크기에 따라 BA가 단조 증가한다.
- **설계:** V-03과 같은 생성기·설계, 시드는 V-03과 겹치지 않음. null 200회, 색 효과 1.5 µV / 3.0 µV 각 30회.
- **실행:** `python research/validation/v03b_null_precision.py 200 30` · 128.9 s · 출력 `reports/runs/V03b/summary.csv`.
- **결과 (관찰된 사실):**

  | 조건 | ERP 4채널 + sLDA | ERP O1·O2 + sLDA |
  |---|---|---|
  | null (200회) | 0.3342 [95% CI 0.3311, 0.3373], p = 0.59 | 0.3349 [0.3314, 0.3385], p = 0.38 |
  | 1.5 µV (30회) | 0.3451 [0.3389, 0.3512] | 0.3513 [0.3427, 0.3599] |
  | 3.0 µV (30회) | 0.3849 [0.3753, 0.3946] | 0.3936 [0.3835, 0.4037] |

- **판정:** H3b **KEEP**. V-03의 오프셋은 우연(편향 없음). 두 파이프라인 모두 색 효과에 민감하며, 후두 채널만 쓰는 쪽이 이 합성 조건(효과가 O1·O2에만 있음)에서 약간 높다.
- **해석 (합성 조건 한정):** 이 잡음 수준에서 O1·O2의 색별 VEP 차이가 최고 약 3 µV면 n = 540, leave-one-block-out BA가 약 39%가 된다. 실제 데이터의 신호·잡음 구조와 같다는 보장은 없다.

## V-04 — 색 순서(스케줄) 관련 교란: 쌍둥이 스케줄, 순열 교환가능성, 직전 색 이월

- **STEP 1 이전 결과:** P002 44.7%(블록 CV, p = 0.001)가 유일한 보정 후 유의 결과. P002·P003·P001의 반복 세션은 같은 seed → 같은 색 순서.
- **STEP 2 문제(사실로 확인):** (a) 저장된 CV 그룹 = 세션×블록 → 테스트 블록의 쌍둥이(다른 세션의 같은 번호 블록, 같은 순서)가 학습에 포함. (b) 순열은 블록 안 시행 단위 셔플 → obs1·obs2(같은 색) 분리, 쌍둥이 블록 간 공유 순서 미재현. (c) 최대 연속 2 제약 → 직전 색이 현재 색에 대한 정보를 가짐.
- **STEP 3 가설:**
  - H4a: (c)의 크기 — 직전 색만 아는 해독기의 BA 상한이 1/3보다 의미 있게 높다.
  - H4b: 색 정보가 없고 세션 내 시간 경과(VEP 진폭의 블록 내 습관화 + 세션 추세, 모든 세션에서 같은 모양)가 있으면, 동일 스케줄 + 저장된 그룹 방식에서 BA가 1/3보다 높아지고 쌍둥이 인식 그룹·서로 다른 스케줄에서는 1/3이다. 반증: 동일 스케줄에서도 BA ≈ 1/3.
  - H4c: 동일 스케줄에서 저장된 시행 단위 순열 null은 반보수적이다(위양성률 > 5%). 반증: 위양성률 ≈ 5% 이하.
  - H4d: 직전 시퀀스 색에만 의존하는 2 µV 이월 성분만으로 BA가 1/3보다 높아진다.
  통제: 파이프라인 F2a ERP(O1,O2)+sLDA 고정, 3세션 × 180 시행, 같은 생성기.
- **STEP 5 실행:** `python research/validation/v04_schedule_confounds.py 30 20 100` · 630.6 s (4코어) · 출력 `reports/runs/V04/{A_schedules,B_summary,C_summary,D_summary}.csv`, `reports/figures/V04_schedule_confounds.png`.
- **STEP 6 결과 (관찰된 사실):**
  - A (설계, 정확값): seed base+1/2/3/8 스케줄의 직전 색 반복 비율 0.224 / 0.247 / 0.188 / 0.212. 생성기 모집단(20,000 블록) P(현재 = 직전) = **0.206** (제약 없는 셔플 0.294). 직전 색만 아는 해독기의 BA 상한 = **0.3935**.
  - B (시뮬레이션, 30회/칸): 동일 스케줄·서로 다른 스케줄 모두, drift 0 / 0.5 / 1.0, 세 그룹 방식 모두 평균 BA 0.327–0.338. 1/3보다 유의하게 높은 칸 없음(최대 t = 1.03).
  - C (시뮬레이션, 20회 × 순열 100회): 위양성률(p ≤ 0.05) — 시행 단위(저장 방식) 0.00 / 0.00, 시퀀스 단위 0.10 / 0.00, 쌍둥이 공유 0.05 / 0.00 (drift 0 / 1). null SD는 세 방식 모두 약 0.025.
  - D (시뮬레이션, 30회): 이월 0 µV 0.3348, 2 µV 0.3388 (t = 1.35, 유의하지 않음).
- **STEP 7 판정:**
  - H4a **KEEP** — 설계상 직전 색 정보는 BA 약 39%까지 설명할 수 있는 크기다(실제 EEG가 직전 색 정보를 담는지는 UNKNOWN → E06).
  - H4b **DISCARD** — 시뮬레이션한 매끄러운 시간 경과 메커니즘은 동일 스케줄에서도 BA를 올리지 않았다. 매끄러운 변화는 블록 단위 수준 이동만 만들고 시행 단위 판별 정보를 거의 주지 않기 때문으로 해석.
  - H4c **DISCARD (이 합성 조건 한정)** — 시행 잡음이 독립인 합성 데이터에서는 저장된 순열 방식이 반보수적이지 않았다. 실제 데이터에서 obs1·obs2가 강하게 상관되면 결과가 달라질 수 있다(UNKNOWN).
  - H4d **INCONCLUSIVE** — 작은 이월 성분은 거의 영향이 없었다. 상한(A)에 가까워지려면 직전 색이 EEG에서 강하게 해독되어야 한다.
- **학술적 의미:** 저장된 CV·순열 방식이 무작위화 구조와 맞지 않는다는 결함은 **구조적 사실**로 남는다. 다만 시뮬레이션한 그럴듯한 메커니즘에서는 그 결함이 위양성을 만들지 않았으므로, 이 결함만으로 P002 결과를 무효로 볼 근거는 없다. 판정은 원본에서 E05·E06을 실행해야 가능하다.

## V-04c — 저장된 CV 그룹 방식에서 '위치만 아는' 해독기 (설계 분석)

- **배경:** 독립 감사(cv-leakage-01)가 "시퀀스 번호만 보고 학습 블록의 다수 색을 고르는 규칙"이 저장된 CV에서 거의 완벽하다고 계산했다. 같은 계산을 독립적으로 재현했다.
- **가설:** H4f 동일 seed 반복 세션이 있는 참가자에서, 저장된 그룹(세션×블록) leave-one-block-out으로 시퀀스 번호만 쓰는 규칙의 BA가 1/3보다 크게 높다. 반증: ≈ 1/3.
- **설계:** 참가자별 세션 구조를 sessions.csv·plan_changes.md에서 재구성(INITIAL_ANALYSIS §4의 추론 포함), 시행 제외 무시(시퀀스당 obs 2개). 규칙: 같은 시퀀스 번호의 학습 시행 다수 색, 없으면 무작위.
- **실행:** `python research/validation/v04c_position_oracle.py` · 0.1 s · 출력 `reports/runs/V04c/position_oracle.csv`.
- **결과 (관찰된 사실):** P001 **1.000**, P002 **1.000** (P002_1125가 세션1 seed일 때) / 0.557 (세션2 seed일 때; 감사자 계산 0.789와 다름 — 동점 처리 방식 차이로 보임), P003 **0.934**, P08 0.333(쌍둥이 없음), 대조(세 세션 모두 다른 seed) 0.304.
- **판정:** H4f **KEEP**. 저장된 평가 구조에서는 시행 위치만 정확히 알면 색을 거의 완벽히 맞힐 수 있다.
- **해석:** 이것은 위치를 정확히 부호화하는 EEG 특징이 있을 때의 **상한**이다. V-04 B처럼 매끄러운 시간 경과는 위치를 거의 부호화하지 못해 영향이 없었다. 반면 이력 의존 반응(직전 색들에 대한 적응·기대)은 동일 순서 세션 간에 그대로 재현되므로 위치의 '지문' 역할을 할 수 있다. 원본에서 쌍둥이 인식 그룹(E05)으로 다시 평가해야 판단할 수 있다.

## V-04b — 색 이력만으로의 예측 가능성 (설계 분석)

- **문제:** 블록마다 색별 6개 고정(비복원 추출) + 최대 연속 2 → 앞선 색들이 다음 색을 부분적으로 결정한다.
- **가설:** H4e 블록 내 이력만 아는 해독기의 정확도가 직전 색 상한(0.39)보다 높다. 반증: ≤ 0.39.
- **실행:** `python research/validation/v04b_sequence_predictability.py 20000` · 3.9 s · 출력 `reports/runs/V04b/{decoders,per_position}.csv`.
- **결과 (관찰된 사실, 20,000 블록):** 직전 색만 0.394, 남은 개수 최다 색 0.505, 남은 개수 + 연속 제약 **0.514** (SE 0.001). 블록 내 위치별: 1번째 0.333 → 9번째 0.490 → 17번째 0.646 → **18번째 1.000** (마지막 시퀀스는 완전히 결정됨).
- **판정:** H4e **KEEP**. 설계상 색 순서에는 강한 이력 의존성이 있다.
- **함의:** 분류기는 시행별 EEG만 보므로 이 구조를 직접 쓰지는 못한다. 그러나 (1) 참가자가 남은 색을 암묵적으로 추적해 **예측(기대)** 하면 자극 직전·초기 EEG에 기대 색이 반영될 수 있고, (2) 반복 세션에서 같은 순서를 외우면 그 효과가 커진다. 저장된 gray1 대조는 gray 시작 후 0.05–0.5 s(색 시작 약 2.5 s 전) 특징만 써서 색 직전의 기대 활동은 검사하지 못했다. → E06에 "색 직전 1 s(−1~0 s) 구간의 다음 색 해독"과 "이력 예측이 맞는 시행 / 틀린 시행으로 층화한 해독 성능"을 추가. 향후 측정 설계는 1차 전이 균형(각 색 앞에 각 색이 같은 빈도로 오는) 순서 또는 블록 내 개수 비고정 방식을 검토할 것.
