## 2. 결론

### 2.1 검증된 사실 (파일·실행으로 확인)

1. 원본 EEG는 이 환경에 없다. 저장된 결과(CSV 5개, PNG 1개)는 원본 없이 재생성할 수 없고, 그 결과 표를 쓰는 코드도 저장소에 없다.
2. 저장된 결과 CSV는 서로 산술적으로 일관된다(V-01, 28/28).
3. 저장된 19개 파이프라인 결과는 모두 사전등록 계획(ERSP + RBF-SVM, 인과 1–30 Hz, −1~2 s, 기준 −1.8~−1.0 s, 60/120 µV)과 다른 탐색 분석이다. 사전등록 주분석의 실데이터 결과는 없다.
4. 기준선(ERP 4채널 + sLDA) 참가자 평균 BA는 33.8%로 우연 수준이다. 최고 평균 파이프라인은 ERP O1·O2 + sLDA 39.6%로, 같은 CV에서 19개 중 고른 값이다.
5. 참가자별 순열 null SD는 2.6–5.9 %p다(V-01). 색 정보가 없는 합성 데이터에서도 n = 540일 때 단일 실행 BA가 24.6–39.8% 범위로 흩어진다(V-03).
6. 기존 파이프라인의 전처리·특징선택·튜닝·증강은 학습 fold 안에서만 fit되며, 색 정보가 없는 합성 데이터에서 19개 모두 null 평균이 1/3과 구분되지 않는다(V-03; 핵심 2개 200회 평균 0.334/0.335, V-03b). 3 µV의 후두 색별 VEP 차이를 주입하면 BA가 약 39%가 된다(합성 조건).
7. 2026-11-24 이전 측정은 모두 세션1 seed라 같은 참가자의 반복 세션은 색 순서가 같다. 저장된 CV(세션×블록 그룹)에서는 시퀀스 번호만 알아도 P001 100%, P003 93%, P002 100%(P002_1125가 세션1 seed일 때)로 색을 맞힐 수 있다(V-04c). 저장된 순열검정은 블록 안에서 시행 단위로 섞는다.
8. 색 순서 설계(블록당 색별 6, 최대 연속 2)에서 P(현재 = 직전) = 0.206이고, 직전 색만으로 BA 상한 39.4%, 블록 내 이력으로 51.4%, 블록의 마지막 시퀀스는 100% 결정된다(V-04, V-04b).
9. 자극 색은 이상적 sRGB에서 회색 배경과 명목상 등휘도다(차이 ≤ 0.6%). 물리적 휘도는 측정된 적이 없다(V-02).
10. `.db` 로더는 도착 시각 타임스탬프를 시간순으로 재정렬할 뿐 dejitter·Sample 카운터 검증·기록 끊김 처리를 하지 않는다. 같은 스트림에서 간격 SD 약 15.7 ms와 음수 간격이 보고되어 있다.
11. P003 데이터는 팀의 미승인 결합 제안과 다르게 구성되었다(11-20 전체 포함, run-08의 블록 3 일부 포함 → 블록 3 시퀀스가 최대 세 CV 그룹에 등장). v2.0 8단계 데이터도 팀 결정 없이 병합되었다.

### 2.2 증거에 기반한 해석

1. **"9가지 ML 기법" 비교에서 기준선 대비 개선을 주장할 근거는 약하다.** 파이프라인 간 차이(−3.3 ~ +5.8 %p)가 참가자별 null 변동 크기이고, 참가자 간 순위 일치도도 낮다(Kendall's W 0.41). 다만 후두 채널 ERP + sLDA는 교차-참가자 선택에서 4번 모두 뽑혔다. 이는 VEP가 후두에서 크고 Fp 채널이 EOG 잡음을 더한다는 신호처리 관점과 맞는다. 탐색 단계의 후보로는 타당하지만, "더 좋다"는 결론은 아니다.
2. **P002의 44.7%는 현재 데이터에서 색 정보가 있다는 가장 강한 증거지만, 아직 색 정보 해독으로 해석할 수 없다.** 이유: (a) 같은 CV에서 고른 최고값이다. (b) 평가 구조상 동일 순서 반복 세션이 학습에 포함되어, 위치·이력을 반영하는 EEG 특징이 있으면 색 없이도 맞힐 수 있다(V-04c 상한). (c) 색 순서가 이력으로 크게 예측되어(V-04b) 기대·적응 활동이 교란이 될 수 있다. 반대 증거: 매끄러운 시간 경과는 시뮬레이션에서 위양성을 만들지 않았고(V-04 B), 저장된 순열 방식도 합성 조건에서는 보정되었으며(V-04 C), gray1 대조(gray 시작 직후 구간)는 우연 수준이었다. 따라서 "결과가 무효"도 "색 해독이 입증됨"도 아니며, 원본에서 쌍둥이 인식 CV·시퀀스 단위 순열·이력 층화(E05, E06, E20)를 해야 판정할 수 있다.
3. **세션 간 일반화는 약하다.** P002 블록 CV 44.7% → 새로운 날 36.0%, 새로운 사람 31–36%. 색 관련 신호가 있더라도 세션마다 달라지는 성분이 크다. 세션별 마커 지연 차이(도착 시각 타임스탬프)가 한 원인일 수 있다(가설).
4. **참가자 간 데이터 품질 차이가 결론을 좌우한다.** 유효 시행 83–533개(6배 차이), P001은 22–24%만 유효. 참가자 평균은 품질이 낮은 참가자를 같은 가중으로 포함한다.

## 3. 해결을 위해 필요한 다음 행동

**연구팀 결정·확인 (에이전트가 대신할 수 없음)**

1. **IRB:** 승인(또는 면제) 번호·승인일과 모든 측정일(특히 2026-11-03 P01/P02), 반복 측정(1회 방문 계획 대비)과 변경1·변경3의 IRB 보고 여부를 대조한다. 승인 범위 밖 데이터가 있으면 분석에서 제외해야 한다.
2. **원본 데이터 접근 방식 (외부 전송 승인 필요):** (a) 실험 PC의 데이터 폴더를 Claude 데스크톱 앱의 Remote Control로 이 세션에 연결하거나, (b) 가명화된 `.db`·`events.csv`(·XDF)를 세션에 올린다. 어느 쪽이든 데이터가 클라우드 환경으로 이동하므로 IRB·동의 범위 안인지 팀이 먼저 판단한다. 또는 (c) 팀 PC에서 직접 `research/` 스크립트와 이후 E-xx 실험을 실행한다.
3. **EVALUATION_PROTOCOL.md §11 결정:** A 주 지표(권고: 사전등록 BA 유지 + Macro-F1 공동 보고), B 사전등록 주분석을 공식 Baseline으로 실행, C 독립 최종 평가 데이터 지정(동결 후 신규 측정), D 포함 세션 기준(v2.0 병합, P003 결합, 반복 세션, 사전 제외 기준), E 실험 예산 승인.
4. **데이터 버전 고정:** 팀 PC에서 `python research/protocol/make_manifest.py <원본 폴더> --out data_manifest.csv` 실행 → 해시를 프로토콜에 기록 → v1.0 동결.

**데이터 접근·승인 후 에이전트가 실행할 순서 (RESEARCH_MAP.md §2)**

5. E01–E03 데이터 무결성·신호 유효성 → E04 사전등록 Baseline → E05–E08, E20 교란 검사 → E09 채널(RQ2) → E10–E14 전처리·시간 구간(1요인씩) → E15–E16 특징·모델(nested) → E18–E19 일반화·통계.

**향후 측정 설계 권고 (V-04·V-04b 근거, 팀·IRB 승인 필요)**

6. 반복 세션은 변경3 규칙(세션별 seed)을 유지한다. 블록 내 이력 예측 가능성을 줄이려면 1차 전이 균형 순서나 블록 내 개수 비고정 방식을 검토한다.
