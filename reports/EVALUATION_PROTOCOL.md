## 3. 분석 단위와 의존 구조

시행(obs1, obs2) ⊂ 시퀀스 ⊂ 블록 ⊂ 세션(측정 실행) ⊂ 참가자.

- obs1·obs2는 같은 시퀀스에서 **같은 색**이다 → 반드시 같은 fold.
- 같은 참가자의 세션이 **같은 seed**(2026-11-24 이전 모든 기록)면 블록 b의 색 순서가 세션 간에 동일하다("쌍둥이 블록"). 이 구조는 CV와 순열검정이 모두 존중해야 한다 (V-04).
- 이어하기 실행(`--start-block`)은 같은 seed 계획의 일부이며 블록 번호를 유지한다. 같은 시퀀스가 두 실행에 중복되면 하나만 사용한다(기존 P003 제안과 동일 원칙).

## 4. 데이터 분할

| 평가 | 외부 분할 | 그룹 정의 | 내부 분할(모델 선택) | 비고 |
|---|---|---|---|---|
| W1 참가자 내 · 세션 내 (확증 주분석) | 세션별 블록 5-fold (leave-one-block-out) | 블록(세션 내) | 학습 4블록 안에서 GroupKFold(블록) | 같은 세션 내 블록은 서로 다른 순서 → 쌍둥이 문제 없음. 세션별 결과 + 참가자 내 세션 평균 |
| W2 참가자 내 · 여러 세션 합침 (탐색) | leave-one-group-out | **같은 seed 세션 간에는 블록 번호**(쌍둥이 블록을 함께 제외), 다른 seed 세션 간에는 세션×블록 | 학습 그룹 안 GroupKFold | 저장된 결과(세션×블록 그룹)는 이 규칙을 따르지 않음 |
| X1 세션 간 일반화 | leave-one-session-out | 세션 | 학습 세션 안 GroupKFold | 같은 seed 세션 간 결과는 "스케줄 공유"로 표기. 서로 다른 seed 세션이 생기면 그것을 주 결과로 |
| X2 참가자 간 일반화 (탐색, 계획상 ≥4명) | leave-one-subject-out | 참가자 | 학습 참가자 안 GroupKFold | EA 등 라벨 미사용 정렬은 테스트 세션 데이터를 쓰는 transductive 방식임을 표기 |

공통 규칙: 스케일러·특징선택·xDAWN·정렬 행렬·증강·튜닝·스태킹 메타학습기는 외부 학습 fold 안에서만 fit (스태킹 내부 CV도 그룹 분할). 시행 내 하위 윈도우를 쓰면 같은 시행의 윈도우는 같은 fold.

## 5. 지표와 집계

- **주 지표: (결정 필요 §11-A)** 사전등록 주지표는 **Balanced Accuracy(BA)** 다. 이번 연구 지시서는 Macro-F1을 주 지표 "후보"로 제시했다.
  권고: 확증 분석의 주 지표는 사전등록대로 BA를 유지하고, Macro-F1을 핵심 보조 지표로 함께 보고한다. (블록당 색별 6시퀀스로 균형 설계라 두 지표는 대체로 비슷하지만, 같지는 않다. 결과를 본 뒤 주 지표를 바꾸면 사후 조정이 된다.)
- 보조 지표: Macro-F1, Accuracy, 클래스별 Recall, MCC, 혼동행렬(행 정규화 + 원시 수).
- 참가자 내 집계: 외부 fold 예측을 모두 모아 1개 값(pooled) + fold별 분포를 함께 보고.
- 집단 집계: 참가자 평균(참가자당 동일 가중) + 참가자 수준 부트스트랩 10,000회 95% CI (사전등록). 참가자 4명 이하에서는 부트스트랩 CI가 불안정하므로 참가자별 결과를 반드시 함께 제시.

## 6. 우연 수준과 비교 기준

| 기준 | 방법 | 용도 |
|---|---|---|
| 균등 추측 | 33.33% | 참고선 |
| Dummy Classifier | `stratified`, `most_frequent`, `uniform` 각각을 같은 외부 분할로 평가 | 실제 비교 기준 |
| 순열 null (추론 기준) | 라벨을 **시퀀스 단위**로(obs1·obs2 함께), 각 블록 안에서 섞되 **같은 seed의 쌍둥이 블록에는 같은 순열**을 적용. 전체 외부 CV를 매번 재실행. 판정용 1,000회(최소 p ≈ 0.001), 탐색용 200회 | p값 |
| 이항 임계값 | 사용하지 않음 (독립 시행 가정이 성립하지 않음; V-01에서 순열 null SD가 iid 이항 SD의 1.14–1.29배) | — |

## 7. 시드

- 외부 CV는 LeaveOneGroupOut이라 결정적이다.
- 확률적 요소(SVC probability, 증강 잡음, LR 등) random_state 목록: `[0, 1, 2, 3, 4]` — 결과는 5개 시드의 평균과 범위로 보고.
- 순열 시드: `0 … n_perm−1`. 합성 검증: V-03/V-04 스크립트의 고정 시드.

## 8. 탐색용 데이터와 최종 평가

- 2026-11-25까지 측정된 모든 세션은 이미 19개 파이프라인 비교·순열검정에 사용되었다 → **손대지 않은 데이터가 없다.** 이 데이터는 탐색(개발) 데이터로만 쓴다.
- 탐색 단계의 모델 선택은 nested CV로 추정한다(선택-인식 추정이지만 독립 평가는 아님).
- **독립 최종 평가 (결정 필요 §11-C)**: 프로토콜·파이프라인 동결 후 측정되는 데이터(변경3 규칙의 새 seed 세션, 신규 참가자)를 최종 평가 데이터로 지정하고, 동결된 파이프라인으로 **1회만** 평가한다. 그 결과는 추가 모델 탐색에 사용하지 않는다.

## 9. 탐색 실험 채택 기준 (KEEP / DISCARD / INCONCLUSIVE / INVALID) — 제안값

- **INVALID**: 데이터 무결성 오류, 누수, 합성 null 보정 실패(아래 §10), 프로토콜 위반.
- **KEEP**: (a) nested 추정 BA가 Baseline보다 참가자 4명 중 3명 이상에서 높고, 참가자 평균 개선 ≥ 2 %p, (b) 시퀀스 단위·스케줄 공유 순열 null에서 개선된 파이프라인이 Baseline보다 나쁘지 않음, (c) gray1 대조가 null 95% 이하 유지, (d) 신호처리 관점의 설명 가능.
- **DISCARD**: 위 (a)를 만족하지 못하고 효과 추정이 0 근처.
- **INCONCLUSIVE**: 방향은 일관되나 참가자 간 불일치 또는 CI가 0을 넓게 포함.
- 모델 채택 여부와 학술적 가치는 따로 기록한다(성능 하락도 기록).

## 10. 누수 방지 검사 (모든 새 파이프라인에 필수)

1. **합성 null 보정**: `research/validation/v03_synthetic_leakage.py` 방식으로 색 정보가 없는 합성 데이터 20회 반복 → 평균 BA가 1/3 ± 2 SE 안. (V-03에서 기존 19개 파이프라인에 적용.)
2. **합성 민감도**: 작은 색 효과를 주입하면 BA가 상승해야 한다.
3. **gray1 대조**: 색이 화면에 없는 gray1 구간을 다음 색으로 라벨링 → null 수준이어야 한다. (주의: 쌍둥이 스케줄·예측(순서 학습) 효과는 gray1에서도 나타날 수 있다.)
4. **자극 전 시간 구간 해독** (−0.2~0 s) → null 수준이어야 한다. 영위상 필터를 쓰면 자극 후 반응이 자극 전으로 번질 수 있다.
