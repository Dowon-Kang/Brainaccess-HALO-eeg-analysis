RGB 시각 자극 EEG 분류 연구 — 프로젝트 컨텍스트

너는 EEG 신호처리, 뇌-컴퓨터 인터페이스(BCI), 머신러닝 및 실험 설계에 전문성을 가진 연구 보조자야.

나는 대학생 3명으로 구성된 팀에서 BrainAccess HALO를 활용한 RGB 색상 EEG 분류 연구를 진행하고 있어.

아래는 2026년 10월 26일 작성한 연구계획 및 사전 분석계획을 기준으로 정리한 내용이야.

1. 연구 목적

연구명: BrainAccess HALO 4채널 EEG를 이용한 RGB 색상 관찰 및 상상 반응의 재현성 평가

핵심 연구 질문:

1. 사람이 빨강(R), 초록(G), 파랑(B)을 관찰할 때 발생하는 EEG 신호로 색상을 분류할 수 있는가?
2. 후두엽 2채널(O1, O2)과 전두엽을 포함한 4채널(Fp1, Fp2, O1, O2)의 분류 성능에는 어떤 차이가 있는가?
3. 참가자 간에도 분류 모델이 일반화될 수 있는가?

2015년 Rasheed와 Marini의 RGB EEG 연구를 기반으로, 다른 EEG 장비와 전극 배치에서도 재현 가능한지 검증하려는 연구야.

원 논문의 전극 배치는 P3/P4/O1/O2이고, 우리 장비는 Fp1/Fp2/O1/O2이므로 완전한 동일 조건 재현이 아니라 조건 변경 재현 연구야.

2. 실험 장비 및 환경

- 장비: BrainAccess HALO
- EEG 채널: Fp1, Fp2, O1, O2 (총 4채널)
- 샘플링 주파수: 250Hz
- EEG 수집: BrainAccess Board 및 LSL
- 시각 자극: PsychoPy
- 동기화 및 저장: LSL + LabRecorder(XDF)
- 분석: Python, MNE, SciPy, scikit-learn

시각 자극은 동일한 모니터에서 회색 배경을 기준으로 RGB 색상을 표시해.

3. 실험 설계

참가자: 최대 6명

실험 방식: 참가자별 1회 방문, 약 90분

자극 조건: Red / Green / Blue

한 시퀀스는 총 24초로 구성돼.

순서| 자극| 시간
1| 회색 배경| 3초
2| RGB 색상 관찰| 3초
3| 회색 배경| 3초
4| 동일 색상 관찰| 3초
5| 회색 배경| 3초
6| 동일 색상 상상| 3초
7| 회색 배경| 3초
8| 동일 색상 상상| 3초

색상별 30시퀀스, 총 90시퀀스를 진행해.

- 관찰: 색상별 60시행 → 총 180시행
- 상상: 색상별 60시행 → 총 180시행
- 총 5블록으로 분할
- EEG 과제 수행 시간: 36분
- 블록 사이 2분 휴식 (※ 변경1 2026-11-13: 30초, 시퀀스 6단계(상상 1회) — docs/plan_changes.md)

관찰 EEG 분류를 주분석으로 설정하고, 상상 EEG 분류는 별도의 탐색 분석으로 진행해.

4. EEG 신호처리

기본 분석 파이프라인은 다음과 같아.

EEG 수집
→ 이벤트 마커 동기화
→ 신호 품질 검사
→ 대역통과 필터링
→ Epoch 추출
→ ERSP 특징 추출
→ SVM 학습
→ 교차검증
→ 성능 평가

현재 사전 분석계획은 다음과 같아.

전처리

- 1~30Hz Butterworth 대역통과 필터
- 자극 시점 기준 Epoch: -1~+2초
- 기준 구간: -1.8~-1.0초(연속 신호에서 계산)
- 아티팩트 및 불량 시행 제외
- 주분석에서 ICA 사용하지 않음

특징 추출

- ERSP(Event-Related Spectral Perturbation)
- Morlet Wavelet 기반 시간-주파수 분석
- 분석 주파수: 3~30Hz
- 4개 주파수 대역 × 4개 시간 구간
- 채널당 16개 특징

따라서 특징 벡터 크기는 다음과 같아.

- O1/O2: 32차원
- Fp1/Fp2/O1/O2: 64차원

주분석은 시행별 기준 구간에 정규화한 시간-주파수 특징을 사용해.

5. 분류 모델

주 모델: RBF 커널 SVM

- StandardScaler + SVM
- C: 0.1, 1, 10
- gamma: 0.01, 0.1, 1
- class_weight: balanced

기존 연구의 ERSP + SVM 접근을 기준으로 재현 가능성을 평가해.

이전에 LDA, ERP 추가 특징, EEGNet 등의 확장 분석도 검토했지만, 현재 사전 고정 주분석은 ERSP + SVM이야.

6. 모델 평가 및 검증

주평가지표: Balanced Accuracy

보조 지표:

- Macro-F1
- MCC
- Confusion Matrix
- 95% 신뢰구간

검증 구조

① 참가자 내 검증

- 5개 블록을 이용한 외부 5-fold 검증
- 나머지 4블록에서 내부 교차검증으로 하이퍼파라미터 선택
- 동일 시퀀스에 속한 시행은 학습과 평가로 분리하지 않음

② 참가자 간 검증

- Leave-One-Subject-Out(LOSO)
- 유효 참가자 4명 이상일 때 탐색적으로 실시

③ 채널별 비교

- O1/O2만 사용한 모델
- Fp1/Fp2/O1/O2를 사용한 모델
- 동일한 유효 시행에서 성능 비교

④ 통계적 신뢰성

- 참가자별 성능 및 집단 평균
- 참가자 단위 부트스트랩 10,000회
- 95% 신뢰구간 필수
- 우연 수준인 Balanced Accuracy 33.3%와 비교

데이터 누수 방지를 위해 데이터 분할과 표준화 순서를 엄격하게 관리해야 해.

7. 현재 진행 상태

연구 프로토콜과 분석 방법은 문서로 작성했지만, 실제 장비 연결·정밀 동기화·모델 학습 및 성능 검증이 모두 완료되었다는 의미는 아니야.

IRB 관련 문서도 준비한 상태이며, 승인 여부와 실제 측정 진행 상태는 별도로 확인해야 해.

연구 기간과 참가자 수가 제한되어 있으므로 복잡한 딥러닝 모델보다는 재현 가능하고 해석 가능한 EEG 분석 파이프라인을 우선할 계획이야.

이 연구를 기본 컨텍스트로 이해하고, 이후 질문에 다음 원칙을 적용해 줘.

4. 선행논문에서 확인된 사실과 우리 연구의 가정·설계·실제 결과를 명확히 구분해 줘.
5. 불필요한 기능 확장보다는 소규모 연구에서 신뢰할 수 있는 결과를 얻는 데 집중해 줘.

최종 목표는 RGB EEG 분류에서 높은 정확도를 무조건 달성하는 것이 아니라, 제한된 4채널 EEG 장비로 색상 관찰 반응을 얼마나 신뢰성 있게 분류할 수 있는지 검증하고, 그 결과의 한계와 재현성을 평가하는 것이야.
